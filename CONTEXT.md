# Call Calendar

Небольшой сервис для публикации доступного времени владельца календаря и записи на звонок. Этот контекст задаёт язык будущих сценариев доступности и записи.

## Language

**Calendar**:
Единый заранее заданный календарь владельца, в котором публикуется доступное для встреч время.
_Avoid_: account, profile

**Slot**:
Фиксированный 30-минутный интервал доступности в календаре.
_Avoid_: time, window

**Booking**:
Запись пользователя на один свободный слот для звонка.
_Avoid_: event, appointment
