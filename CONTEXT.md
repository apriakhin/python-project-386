# Call Calendar

A service for booking calls into fixed, conflict-checked time slots.

## Language

**Slot**:
A fixed time interval that can be booked.
_Avoid_: time block, window, timeslot

**Booking**:
The reservation of a Slot.
_Avoid_: appointment, reservation

**Call**:
A scheduled conversation created by a Booking. The upcoming section lists Calls under the UI label «Предстоящие события».
_Avoid_: meeting, appointment

**Landing page**:
The public page that explains the service and links to the Booking page.
_Avoid_: home page, index page

**Booking page**:
The page where a visitor picks a Slot and books a Call.
_Avoid_: reservation page, schedule page
